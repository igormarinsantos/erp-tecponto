<objective>
Audit AUDIT-04 for real: confirm the cost/margin guard covers every PDV and trade-in response surface, not just the one endpoint the existing `_check_pos_item_cost_guard` inspects. Close whatever gap that audit finds, in the backend.

Purpose: per 03-CONTEXT.md's AUDIT-04 entry, the existing coverage is partial — `_check_pos_item_cost_guard` (test_frontend_api.py:8902-8968) inspects only `search_pos_items`. GEMINI.md section 1.1 makes this non-negotiable: the Python server must never serialize cost to Atendente/Gestor/Técnico, and hiding it in React does not count.
Output: one new systematic guard test wired into the suite, plus any serializer fix it forces.
</objective>
