# Documentacao Tecponto

Esta pasta e a copia versionada dos guias que orientam o desenvolvimento do
ERP Tecponto. O codigo e os documentos devem evoluir juntos.

## Ordem de leitura

1. `00_contexto_tecponto.md`
2. `01_roadmap_fases.md`
3. `tecponto_regras_de_negocio_travadas.md`
4. O guia da fase ou bloco em execucao

## Fonte de verdade

`tecponto_regras_de_negocio_travadas.md` define as regras e campos travados.
Nenhuma implementacao pode contradizer esse documento.

## Guias incluidos

- Fundacao e modelo: Fases 0, 1 e 2.0
- Pilares de negocio: REPARE (2.1), TROQUE (2.2) e COMPRE (2.3)
- Superficies e frontend: Fase 3, design system e blocos 3.5 a 3.9
